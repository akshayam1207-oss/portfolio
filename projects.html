Accident Detection & Emergency Alert System

🚨

A smart, sensor-driven system that detects vehicle accidents automatically and sends an emergency alert — along with the vehicle's live location — to predefined emergency contacts, cutting down the time it takes for help to arrive.

Python Machine Learning IoT Arduino Sensors
View on GitHub
Problem

Road accidents often go unreported for critical minutes because there's no one nearby to call for help, and emergency responders have no way of knowing where or when a crash happened.

Solution

An IoT device fitted with sensors continuously monitors the vehicle. When it detects the signature of a collision, it automatically triggers an alert — packaged with the vehicle's location — sent straight to emergency contacts.

Outcome

A working prototype that removes the need for a manual call after a crash, helping close the gap between when an accident happens and when help is notified.

02 / 03

Fake Job Detection System

🕵️

A Flask web application that analyses job postings for scam indicators, assigns a Low, Medium or High risk level, and helps job seekers steer clear of fake recruitment offers.

Python Flask Pattern Recognition Keyword Analysis
View on GitHub
Problem

Fraudulent job listings are common on online platforms, and it's hard for job seekers to tell a genuine opportunity from a scam based on the posting text alone.

Solution

A Flask web app that scans a job description for scam patterns and suspicious keywords, then assigns a risk level (Low, Medium or High) so a listing can be checked in seconds.

Outcome

A working web interface that gives job seekers a quick, rule-based second opinion before they apply or share personal information.

Voice as a Bridge for Autism Communication

🗣️

A communication support system that helps autistic children express their needs more effectively through voice-assisted interaction, making everyday communication easier between children, parents, and caregivers.

Java (Spring Boot) Artificial Intelligence Voice Processing
View on GitHub
Problem

Many autistic children find it difficult to express their needs verbally, which creates a communication gap between them and the parents or caregivers trying to understand and support them.

Solution

A Java Spring Boot backend for a Voice to Image Selector: spoken input is matched to images, giving children an accessible, visual way to communicate their needs.

Outcome

A working assistive tool aimed at making day-to-day communication smoother for autistic children and the people who care for them.
